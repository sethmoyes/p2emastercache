# Compendium

One note per recurring person, group, god, item or place hub, Each note says what the thing *is* (book canon, with room
links). For everything that
*happened* with it, open the note and look at its **backlinks** panel:
every session, roster and floor doc that mentions it is listed there.

Hover any name in any session file to preview its note. Spellings from the
table ("[[Korlok|Corlock]]," "[[Boss Skrawng|Skrugg]]," "[[Carman Rajani|Carmen]]") are stored as `aliases`, so they link
here too, and Obsidian's "unlinked mentions" finds them in the raw OneNote
imports.

The full table, with more views (factions, floors, shops), is
[[Compendium.base]].
