# Floors — Abomination Vaults deep-dive reference

**GM-only, full spoilers.** One doc per dungeon level (plus the campaign/[[00-campaign-overview-and-otari#The Town of Otari|Otari]] overview),
encoded from Your Pocket GM's *Abomination Vaults – Video Tutorial* series
([playlist](https://www.youtube.com/playlist?list=PLvubkmE4otwwURK_BoftbCalqFCyEWTnm)) by the
**`/video-encoder`** skill (`.claude/skills/video-encoder/`; scripts in `tools/`).

Each doc: backstory, town/story beats, every room with DCs/creatures/treasure/XP, and
quick-reference tables (XP, DCs, keys, secret doors, cross-floor connections, creatures,
treasure, cast), plus an F-numbered list of caption uncertainties and repo discrepancies.
Raw timestamped transcripts are in [`transcripts/`](transcripts/).

Chapter N = Floor N = Level N. Room codes use the level's letter (A=1 … J=10; E=5 is the Arena).
