# Bugfix Requirements Document

## Introduction

When viewing merchant tables on the Players or GM screens, the Image column displays raw HTML text instead of rendering as actual HTML elements. This prevents users from seeing the "Show Image" buttons and viewing item images. The issue occurs because the HTML generated by `convert_table_to_html()` is being escaped somewhere in the rendering pipeline, causing HTML tags and attributes to display as plain text instead of being interpreted as markup.

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN a merchant table with images is loaded on the Players screen THEN the Image column displays raw HTML text like `class="hidden max-w-xs h-auto rounded border border-gray-600 mt-2 row-image"loading="eager"alt="..."` instead of rendering the HTML elements

1.2 WHEN a merchant table with images is loaded on the GM screen THEN the Image column displays raw HTML text instead of rendering the HTML elements

1.3 WHEN the HTML is generated by `convert_table_to_html()` THEN the resulting HTML string is being escaped during the markdown-to-HTML conversion process

1.4 WHEN table HTML is inserted into the result list in `markdown_to_html()` THEN subsequent paragraph processing wraps the HTML in `<p>` tags and escapes the content

### Expected Behavior (Correct)

2.1 WHEN a merchant table with images is loaded on the Players screen THEN the Image column SHALL display a "Show Image" button that can be clicked to reveal the preloaded image

2.2 WHEN a merchant table with images is loaded on the GM screen THEN the Image column SHALL display a "Show Image" button that can be clicked to reveal the preloaded image

2.3 WHEN the HTML is generated by `convert_table_to_html()` THEN the resulting HTML SHALL be preserved as raw HTML without escaping

2.4 WHEN table HTML is inserted into the result list in `markdown_to_html()` THEN the paragraph processing SHALL skip HTML blocks and not wrap them in `<p>` tags

2.5 WHEN the "Show Image" button is clicked THEN the button text SHALL change to "Hide Image" and the image SHALL be displayed

2.6 WHEN the "Hide Image" button is clicked THEN the button text SHALL change to "Show Image" and the image SHALL be hidden

2.7 WHEN the "Expand All Images" button is clicked THEN all images in the table SHALL be displayed and all buttons SHALL show "Hide Image"

2.8 WHEN the "Collapse All Images" button is clicked THEN all images in the table SHALL be hidden and all buttons SHALL show "Show Image"

2.9 WHEN the "View All Items (Grid)" button is clicked THEN a modal SHALL display showing all item images in a grid layout

2.10 WHEN an item in the grid view has no image THEN the item name SHALL be displayed as text instead of an image

### Unchanged Behavior (Regression Prevention)

3.1 WHEN markdown headers are processed THEN the system SHALL CONTINUE TO convert them to styled HTML headers

3.2 WHEN markdown lists are processed THEN the system SHALL CONTINUE TO convert them to styled HTML lists

3.3 WHEN markdown bold and italic text is processed THEN the system SHALL CONTINUE TO convert them to styled HTML

3.4 WHEN markdown links are processed THEN the system SHALL CONTINUE TO convert them to styled HTML links

3.5 WHEN non-table content is processed THEN the system SHALL CONTINUE TO wrap text in paragraph tags

3.6 WHEN tables without images are processed THEN the system SHALL CONTINUE TO render them correctly

3.7 WHEN the merchant selector dropdown is used THEN the system SHALL CONTINUE TO load merchant content correctly

3.8 WHEN the map zoom controls are used THEN the system SHALL CONTINUE TO function correctly
